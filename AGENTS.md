# AGENTS.md

Guidance for AI agents and humans working in this repository.

## Project TodoApp

- React
- TypeScript (strict; `src/` is all `.ts` / `.tsx`)
- Vite
- Tailwind CSS
- Component — shadcn/ui

## Commands

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the Vite dev server |
| `npm run lint` | ESLint, including the React Hooks rules |
| `npm run typecheck` | `tsc -b` across the app and the Vite config |
| `npm run build` | Typecheck, then production build into `dist/` |
| `npm run preview` | Serve the production build |

Run `npm run lint` and `npm run build` before committing. Both must pass clean.

## Layout

```
src/
  App.tsx                 route table (single source of truth for routes)
  main.tsx                BrowserRouter + AuthProvider + CartProvider mount
  context/                auth-context.ts / AuthProvider.tsx
                          cart-context.ts / CartProvider.tsx
  hooks/                  useFetch.ts (generic), useAuth.ts, useCart.ts
  types/                  User, Todo / TodoFilter, Product
  components/layout/      AppLayout, NavBar, LiveClock, WindowWidth
  components/todos/       AddTodo, FilterBar, TodoList, TodoItem  (all stateless)
  components/users/       UserCard, UserListSkeleton
  components/cart/        CartLines, CheckoutSummary  (both take no props)
  components/ui/          generated by the shadcn CLI — do not hand-edit
  pages/                  TodosPage, UsersPage, UserDetailPage,
                          ShopPage, CheckoutPage, NotFoundPage
  lib/                    api.ts (endpoints), catalog.ts, money.ts, utils.ts (cn)
```

Each context is three files on purpose — the `.ts` module holds the types, the
context object and (for the cart) the reducer; the `.tsx` file holds only the
provider component; the hook lives in `hooks/`. That keeps every file exporting
either components or values, so `react-refresh/only-export-components` passes
without an eslint-disable.

## Rules this codebase is held to

1. **Shared state lives in exactly one component.** The todo array is owned by
   `pages/TodosPage.jsx`. `AddTodo`, `FilterBar`, `TodoList` and `TodoItem` hold
   no copy of it — data goes down as props, intent comes back up as callbacks.
   A child may own private UI state (the text in its own input); it may never
   own a second copy of something a sibling also needs.
2. **Anything derivable is derived during render,** not stored in state. Filtered
   lists and counts are computed from `todos`; a second copy is the thing that
   goes stale.
3. **Every effect lists only the values it reads.** `react-hooks/exhaustive-deps`
   is set to `error`, not `warn`. Do not silence it with an eslint-disable —
   fix the effect.
4. **Every listener, timer and in-flight request gets a cleanup.** See the effect
   table in `README.md`. A new effect without a cleanup needs a comment saying
   why it does not need one.
5. **Every fetch inside an effect is guarded by a `cancelled` flag** (and an
   `AbortController`), so a stale response can never overwrite fresher state.
6. **Fetches check `response.ok`.** `fetch` does not reject on 4xx/5xx; the error
   state has to be raised by hand.
7. **Navigation uses `Link` / `NavLink`,** never `<a href>` for internal routes —
   an `<a>` triggers a full page reload and throws away all app state.
8. **State two distant components share goes in a context, not through props.**
   The signed-in user and the cart are read with `useAuth()` / `useCart()`.
   No prop carries cart data anywhere in the tree — not even a formatted total.
   A context's consumer hook throws when its provider is missing, so its return
   type is never `| null`.
9. **Every cart rule lives in `cartReducer`, and nowhere else.** Components
   dispatch a member of the `CartAction` union and say what happened; the
   reducer decides what the cart becomes. A component must never pre-apply a
   rule (for example, deleting a line itself when a quantity reaches zero).
10. **Screenshots are not committed.** They are zipped with the hand-in;
    `*.zip` is in `.gitignore`. The `docs/screenshots/*.png` files predate this
    rule and stay because the README links them.

## Adding shadcn components

```bash
npx shadcn@latest add <component>
```

Files land in `src/components/ui/`. They are generated: re-running the CLI
overwrites them, so keep customisations in your own components.
